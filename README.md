# Уроки — Telegram Mini App

Веб-версия того же самого учёта учеников и уроков, но открывается прямо
внутри Telegram как приложение (без переписки с ботом кнопками).
Использует **ту же базу данных Postgres**, что и `tutor_bot` — это
буквально два разных интерфейса к одним и тем же данным. Можно менять
ученика в приложении, а «Уроки сегодня» смотреть потом в чате бота —
всё синхронно, это одна база.

## Структура проекта

```
tutor_app/
├── app.py             # Flask: отдаёт страницу приложения + API
├── db.py               # та же логика работы с базой, что у бота
├── telegram_auth.py    # проверка, что запрос действительно из Telegram
├── config.py
├── schema.sql
├── requirements.txt
├── .python-version
├── static/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── README.md
```

## Шаг 1. Залить код в GitHub

Добавьте папку `tutor_app` в репозиторий — рядом с `tutor_bot`, отдельной
папкой в корне (или в отдельный репозиторий — как удобнее). Не забудьте
скрытый файл `.python-version` (см. заметку про него в README бота —
GitHub иногда его "теряет" при загрузке через браузер, проверьте, что
файл появился в репозитории).

## Шаг 2. Настроить сервис tutor_app на Render

Вы уже создали Web Service `tutor_app` — зайдите в его **Settings**:

1. **Root Directory**: `tutor_app` (если код лежит в подпапке репозитория).
2. **Build Command**: `pip install -r requirements.txt`
3. **Start Command**: `gunicorn app:app --bind 0.0.0.0:$PORT`
4. **Instance Type**: `Free`.
5. **Environment** — те же три переменные, что и у бота:
   - `BOT_TOKEN` — тот же токен, что у `tutor_bot`
   - `DATABASE_URL` — та же база, что у `tutor_bot` (важно: именно та же —
     тогда оба интерфейса видят одних и тех же учеников)
   - `ALLOWED_USER_IDS` — тот же ваш user id
6. Сохраните и запустите деплой (Manual Deploy → Deploy latest commit).

После успешного деплоя Render покажет адрес сервиса вида
`https://tutor-app-xxxx.onrender.com` — он вам понадобится в следующем шаге.

## Шаг 3. Привязать приложение к боту через BotFather

Это единственный шаг, где нужно что-то настроить в самом Telegram —
код бота трогать не нужно:

1. Откройте **@BotFather**, отправьте `/mybots`, выберите вашего бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Пришлите URL вашего сервиса из шага 2 (например
   `https://tutor-app-xxxx.onrender.com`).
4. Затем пришлите текст кнопки, например `Открыть приложение`.

Готово — рядом со строкой ввода в чате с ботом появится кнопка,
которая открывает мини-приложение прямо внутри Telegram.

## Как устроена защита доступа

Telegram при открытии приложения передаёт ему данные о пользователе,
подписанные секретом на основе токена бота (`initData`). Приложение
на каждый запрос проверяет эту подпись (`telegram_auth.py`) и сверяет
ваш Telegram id со списком `ALLOWED_USER_IDS` — точно так же, как
это уже устроено в боте. Открыть и пользоваться приложением может
только тот, чей id в этом списке; из обычного браузера (не через
Telegram) запросы отклоняются.

## О «холодном старте» на бесплатном тарифе

Как и у бота, бесплатный Web Service на Render засыпает через
~15 минут без запросов. Если вы не открывали приложение какое-то
время, первое открытие может занять секунд 30–60, пока сервис
проснётся — дальше всё работает быстро. Это не ошибка.

## Что можно делать в приложении

- **Ученики** — список, добавление, редактирование имени/цены,
  ссылки на встречу и на доску, комментарий об ученике (у каждого
  поля есть кнопка «📋» для быстрого копирования), управление
  регулярным расписанием, удаление. На карточке ученика в списке —
  быстрые кнопки копирования ссылок/комментария без открытия деталей.
- **Уроки** — уроки за выбранную дату (по умолчанию сегодня), отметка
  ✓/✕, удаление, стрелки для переключения дня (починены — раньше
  «вперёд» из-за часового пояса телефона иногда не двигал дату),
  кнопка добавления урока вне расписания. Нажатие на имя ученика в
  строке урока открывает комментарий именно к этому уроку (значок 💬
  показывает, что комментарий уже есть).
- **Неделя** — обзор всех уроков на 7 дней вперёд от выбранной даты.
- **Расчёт** — сверху обзор за месяц (с переключением месяца
  стрелками): запланированная выручка (все уроки месяца, кроме явно
  отменённых), фактическая выручка (только уже проведённые), налог
  10% отдельно от плана и от факта, а также список учеников с суммой
  за месяц и чекбоксом «Оплатил(а)». Ниже — расчёт по конкретному
  ученику за период (неделя/месяц/свои даты) с кнопкой «Скопировать
  текст для ученика»: копирует чек вида
  `📊 Уроки за Август 2026: / 📅 03.08, 07.08, ... / 🔢 Всего: 11 /
  🪙 Итого: 165 руб.` (валюта — рубли или $ — выбирается тут же и
  запоминается).
- **Резервная копия** — можно скачать файл `.json` со всеми данными
  (ученики, расписание, история уроков, оплаты, настройки) и
  восстановить из такого файла обратно, а также, на всякий случай,
  скопировать/вставить те же данные текстом через буфер обмена.
- Верхняя шапка теперь учитывает системную область телефона (время,
  батарея, «чёлка»/шторка) через `safeAreaInset` Telegram — кнопки
  сверху больше не перекрываются.

Бот (`tutor_bot`) продолжает работать как раньше и никак не пострадал —
теперь это просто два способа попасть в одни и те же данные.
